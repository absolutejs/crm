## 0.0.10-alpha.11 — 2026-10-02

### Security

- **HubSpot webhook signatures are compared in constant time, timestamps must be integers within the allowed window in either direction, and the request URI is decoded the way HubSpot signs it.**

### Added

- **verifyHubSpotAppRequest and uninstallHubSpotApp (with the HubSpotAppContext type) verify signed HubSpot app requests and handle app uninstalls. exportCRMContacts exports contacts from a CRM adapter.**

### Changed

- **HubSpot webhook event ids are now a SHA-256 of the app, portal, subscription and event identifiers instead of hs:<eventId>. Deduplication keys stored before this release will not match new events. HubSpot privacy deletions are treated as deletes, and malformed entries in a batch are skipped instead of failing it.**
